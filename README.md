# 每周考试成绩追踪

一个用于记录和追踪学生每周考试成绩的轻量 Web 应用。多用户、多设备同步，支持学校/年级管理。

## 功能

- **成绩记录**：考试日期、语文/数学/英语三科成绩与排名，保存后可随时编辑修改
- **同次考试对比**：以「周次标签」识别同一次考试，自动把全班学生的成绩横向拉到一起比较
- **错题本**：记录错题、错题分类，并支持上传题目照片（自动压缩后存储）
- **统计看板**：按周次聚合，展示趋势与对比；单次考试不生成虚假趋势
- **多用户与权限**：每人独立账号密码，只能修改自己的数据；管理员可查看和编辑所有人的数据
- **自主注册 + 审批**：用户可自助注册，用户名按拼音首字母自动生成，需管理员后台审批通过后生效
- **学校 / 年级**：用户可设置所在学校与年级（默认六年级、初一），每年 9 月 1 日自动升年级，高三封顶
- **响应式界面**：手机与电脑浏览器自适应

## 技术栈

- 前端：单文件 `index.html`，原生 JavaScript，无框架、无构建步骤
- 后端：纯 Node.js `server.js`，**零第三方依赖**
- 存储：JSON 文件持久化，通过 `DATA_DIR` 环境变量外置数据目录

## 运行

```bash
node server.js
# 默认端口 3000，可通过 PORT 环境变量覆盖
```

生产环境建议把数据目录挂到持久化卷，避免重新部署时数据丢失：

```bash
DATA_DIR=/appdata node server.js
```

## 数据与安全说明

以下文件属于运行时数据，**已在 `.gitignore` 中排除，不会进入版本库**：

| 文件 / 目录 | 说明 |
| --- | --- |
| `data.json` | 用户账号（含口令哈希与盐）、考试记录、错题数据 |
| `config.json` | 会话签名密钥（缺失时服务端自动重新生成） |
| `backups/` | 发布前的云端数据快照 |

> 首次启动时服务端会自动创建 `data.json` 与管理员账号 `admin`。请登录后立即修改默认密码。
